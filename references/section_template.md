# C802 各章節模板與撰寫範例指南（參考文件）

> 本文件整合**國科會作業要點規範**與**清華大學分子醫學研究所 林玉俊教授**之「15分鐘學會如何撰寫大專生研究計劃書」核心心法。
> 核心原則：**文法文句可用 AI 潤飾，但「邏輯」是評審最重視且唯一無法替代的靈魂**。

---

## 一、各章節篇幅配置建議（主文 ≤ 10 頁）

| 章節 | 建議篇幅 | 核心任務 |
|---|---|---|
| **摘要（C803）** | 0.5 頁（300～500 字） | 計畫完成後最後撰寫，濃縮動機、問題、方法、初步結果與未來效益 |
| **1. 研究動機與研究問題** | 0.5 ～ 1 頁 | 漏斗式推演：由大背景收斂至具體核心問題，說服研究重要性 |
| **2. 文獻回顧與探討** | 約 2 頁 | 詳細論證動機，三段式鋪陳領域背景、已知進展、未知研究缺口（Gap） |
| **3. 研究方法、步驟與預期結果** | 2 ～ 3 頁 | 整體技術策略 + 3 個具體實驗目標（Specific Aims） + **展示初步結果** |
| **4. 需要指導教授指導的內容** | 0.5 頁 | 定期討論、實驗技術指導、研討會發表與論文改寫規劃（呼應評審第 4 點） |
| **5. 參考文獻** | 依需求（不占 10 頁上限） | 善用 Mendeley／EndNote 管理工具，確保真實 DOI 與統一格式 |

## 二、章節撰寫結構與具體範例

### 1. 摘要（建議篇幅：0.5 頁，300 ～ 500 字）

* **核心目標**：短時間內讓審查委員精準掌握全案精華（建議計畫全文書寫完畢後最後撰寫）。
* **五段式黃金公式**：
  1. **背景動機（2～3 句）**：說明該議題之嚴重性、未解難題或產業重要性。
  2. **研究問題（1～2 句）**：過去發現特定目標可能扮演重要角色，但其詳細機制或關鍵瓶頸仍不清楚。
  3. **研究方法與策略（2 句）**：簡述使用何種核心技術/模型、評估哪些具體指標。
  4. **初步結果（1～2 句）**：強調已成功建立關鍵材料、模型或實驗平台，具備高度可行性。
  5. **未來效益與展望（1～2 句）**：說明本研究成果對學術理解、臨床應用或技術落地的預期貢獻。

#### 【範例】肺癌與分子 Triple X 探討
```markdown
【研究背景與動機】肺癌長年位居國人癌症十大死因之首，臨床上多數患者確診時已發生癌細胞轉移，因致病與惡化分子機制尚未完全明瞭，目前仍缺乏有效之根治療法。
【研究問題】過去文獻發現候選蛋白 Triple X 於肺癌組織中呈現顯著高度表現，然而 Triple X 究竟如何調控癌細胞增殖與轉移能力，其確切分子途徑至今仍不清楚。本計畫旨在深入探討 Triple X 於肺癌惡化進程中扮演之關鍵病理角色。
【研究方法】本研究擬利用 RNA 干擾（RNAi）技術於肺癌細胞株中專一性抑制 Triple X 之表現，並進一步評估其對細胞增殖速率、平面爬行遷移（Migration）以及穿透基底膜侵入（Invasion）能力之影響。
【初步結果】研究團隊目前已成功建立人類肺癌細胞株培養系統，並透過短暫轉染驗證 RNAi 可有效降低 Triple X 蛋白質表現量逾 70%，相關細胞功能性分析平台亦已就緒。
【未來效益】本研究成果預期將釐清 Triple X 在肺癌生長與轉移中的調控網絡，為未來開發新型肺癌標靶診斷與治療策略提供堅實之學術基礎。
```

### 2. 研究動機與研究問題（建議篇幅：0.5 ～ 1 頁）

* **核心目標**：說服審查委員該研究的**重要性與必要性**。
* **漏斗式邏輯推演（由大到小收斂）**：
  1. **廣泛背景**：例如肺癌為國人十大死因之一，且目前尚無完全根治療法。
  2. **延伸研究問題**：肺癌發生轉移的機制仍不清楚，因此想探討其相關分子機制。
  3. **聚焦特定目標（Triple X）**：提出背景知識說明為何選擇此分子（例如：過往研究發現 Triple X 在肺癌組織中大量表現、或基因剔除鼠易/不易發生肺癌）。
  4. **收斂至具體主題**：一步步推導出本次計劃要探討「Triple X 在肺癌細胞增殖與爬行中的角色」。

#### 【通用跨領域收斂模板】
* **醫學/生命科學類**：
  重大死因或疾病嚴重性 $\rightarrow$ 關鍵轉移/致病機制未明 $\rightarrow$ 文獻指出分子 X 與其強烈相關 $\rightarrow$ 探討分子 X 的功能機制。
* **基礎科學/理學類**：
  重大科學問題半世紀以來未有定論 $\rightarrow$ 過去假說存在衝突或觀測死角 $\rightarrow$ 提出新的觀察視角或微觀模型 $\rightarrow$ 驗證核心科學假說。
* **資訊/工程技術類**：
  現有技術面臨性能/精度瓶頸 $\rightarrow$ 傳統演算法或架構無法克服特定邊界條件 $\rightarrow$ 引入新型混合架構或演算法 $\rightarrow$ 建立原型並評估改善效益。

### 3. 文獻回顧與探討（建議篇幅：約 2 頁）

* **核心目標**：對前述研究動機進行詳細文獻論證，建立堅實的學術依據，並明確凸顯「研究缺口（Research Gap）」。
* **三段式論述結構與範例**：
  * **第一段（廣泛背景深入剖析）**：詳細回顧肺癌之流行病學統計、各分期存活率、現有標靶/化療藥物抗藥性，點出「轉移與復發」是致命根源。
  * **第二段（聚焦目標之已知進展與矛盾/缺口）**：回顧 Triple X 的發現歷史、蛋白質結構與已知生物功能；列出近期期刊文獻發現 Triple X 與不良預後相關的證據，但點出「其下游信號傳導途徑與促癌轉移之機轉仍是學界盲點」。
  * **第三段（本研究之切入定位）**：說明本研究如何透過特定細胞株模型，系統性驗證 Triple X 之表型影響，銜接前人未竟之處。

#### 【文獻比較與缺口矩陣格式】
| 文獻（作者, 年份） | 研究對象 / 方法 | 主要發現 | 現存限制與研究缺口 | 本計畫切入點 |
|---|---|---|---|---|
| Smith et al. (2023) | 非小細胞肺癌臨床檢體 | Triple X 高表現與低存活率相關 | 僅具臨床相關性，未驗證細胞功能 | 以體外細胞模型驗證增殖與侵入能力 |
| Lee et al. (2024) | 基因敲除小鼠模型 | Triple X 缺乏可延緩腫瘤成長 | 缺乏細胞遷移與侵襲之動態微觀機轉 | 採用 Wound Healing 與 Transwell 深入解析 |

### 4. 研究方法、步驟與預期結果（建議篇幅：2 ～ 3 頁，評審最看重）

* **核心目標**：向評審證明「技術路線清晰、目標明確、完全做得到」。
* **撰寫架構**：
  1. **整體技術平台與研究設計**：簡述整體實驗邏輯（例如：透過 RNAi 抑制肺癌細胞中 Triple X 表現，比對實驗組與對照組在表型上的差異）。
  2. **拆解為 3 個具體實驗目標（Specific Aims）**：
     * **Aim 1：探討 Triple X 對肺癌細胞增殖（Proliferation）的影響**
       * *實驗邏輯*：腫瘤增殖代表癌細胞生長擴大之能力。
       * *測量方法*：利用細胞計數法（Cell Counting）、MTT 存活率分析或增生標記（PCNA / Ki-67）螢光染色，紀錄不同時程之增長曲線。
     * **Aim 2：探討 Triple X 對肺癌細胞爬行遷移（Migration）的影響**
       * *實驗邏輯*：細胞爬行是癌細胞脫離原發病灶、展開轉移的初始關鍵步。
       * *測量方法*：採用傷口癒合試驗（Wound Healing Assay），在顯微鏡下定期拍照量化刮痕癒合面積與爬行速度。
     * **Aim 3：探討 Triple X 對肺癌細胞組織侵入（Invasion）的影響**
       * *實驗邏輯*：侵入代表癌細胞分泌酵素降解細胞外基質（ECM）並侵蝕血管轉移之能力。
       * *測量方法*：利用包覆 Matrigel 基底膜之 Transwell 腔室試驗，量化穿透至下層膜表面之細胞數。
  3. **【必備決勝點】展示豐富且具體的初步結果（Preliminary Results）**
     * **關鍵心理暗示**：向評審展示「我們萬事俱備，材料系統皆已就緒，只差核發研究補助款即可順利產出」。
     * **具體範例**：
       * 附上實驗室已成功培養、健康貼壁生長的肺癌細胞株相位差顯微鏡照片（證明材料無虞）。
       * 附上 RT-PCR 或 Western blot 影像數據，證明團隊已成功合成專一性 siRNA 並顯著抑制 Triple X 之表現（證明技術無虞）。
       * 附上實驗室已標準化之 Wound Healing 或 Transwell 測試校正圖（證明分析平台已建立）。

  4. **【加分核心策略】個人經歷與執行能力「無痕融入法（實務火力展示）」**
     * **為什麼要融入「研究方法」中？**
       * C802 官方格式沒有「個人簡歷」欄位；若強行塞在動機或文獻，會顯得突兀且不合學術規範。
       * 融入「研究方法步驟」中，是以「**技術可行性背書（Feasibility Guarantee）**」之名，行「**實戰火力展示**」之實。
       * 審查委員看到時，心中會立刻給予高度肯定：「這個大專生不是只在講空話，他過去就做過類似系統／管線，8 個月絕對能高水準收斂！」（直接攻下官方第 7、8 項審查高分）。
     * **三大最佳融入錨點與示範句型庫**：
       * **錨點 A：資料採集、清洗與自動化管線（對應 Step 1）**
         * *句型*：「在資料蒐集與標註自動化方面，申請人過去具備使用 [工具，如 Playwright / Selenium] 撰寫 RPA 自動化腳本與資料爬取之實務經驗，能高效構建自動化清洗與多重標註驗證管線，確保基準資料集之純淨度與一致性。」
       * **錨點 B：核心模型串接、Prompt 工程與微調（對應 Step 2 / Step 3）**
         * *句型*：「在對抗樣本生成管線與 API 整合上，申請人曾於 [機構/專案，如企業實習/專案] 實作 [系統，如企業級 RAG 知識庫/智慧助理]，熟悉商用大語言模型（OpenAI GPT-4o / Claude）之 API 深度串接、Prompt Engineering 與參數調校，具備充足的實戰經驗來設計多輪次對抗攻擊提示詞並確保生成效率。」
       * **錨點 C：系統架構、全端部署與分散式環境（對應 Step 3 / Step 4）**
         * *句型*：「在模型微調與推論環境建置上，申請人具備 [全端/軟硬整合，如 FastAPI+PostgreSQL 全端開發 / EdgeSight 軟硬體整合] 之專案架構經驗，熟悉 CUDA 硬體加速環境配置與推論排程，具備獨立排除底層驅動與記憶體瓶頸之技術韌性，確保各組對照模型訓練能穩定推進。」

### 5. 需要指導教授指導的內容（建議篇幅：約 0.5 頁）

* **核心目標**：展現學生積極性與教授指導的實質具體性，呼應國科會審查第 4 要點（指導教授指導能力與投入度）。
* **四大核心指導面向**：
  1. **實驗技術培訓與安全規範**：由指導教授及資深研究員帶領細胞培養無菌操作、分子生物技術（RNAi/Western blot）訓練及實驗室生物安全規範。
  2. **定期學術討論機制（Meeting）**：每週固定參與實驗室 Group Meeting 匯報數據，並每雙週進行 1 對 1 指導討論，滾動式修正實驗設計。
  3. **資料分析與科學批判思維**：指導統計檢定方法、實驗重現性確認及數據圖表嚴謹呈現。
  4. **研討會發表與論文撰寫**：指導期末海報製作，並規劃於國內相關學術研討會發表成果，後續輔導改寫為學術論文。

### 6. 參考文獻（不占 10 頁上限）與文獻管理工具

* **文獻數量與年代**：建議 15 ～ 25 篇，優先引用近 3 年經同行審查之國際主流期刊論文。
* **善用文獻管理工具（Mendeley / EndNote）**：
  * **拖曳 PDF 自動建檔**：將下載之論文 PDF 拖入 Mendeley，軟體自動解析標題、作者、年份與期刊資訊，支援全文檢索。
  * **雲端跨電腦同步**：註冊帳號享有同步空間，實驗室同儕與個人不同電腦間文獻庫無縫共享。
  * **Word 插件一鍵引用（Mendeley Cite / EndNote CWYW）**：在 Word 撰寫時直接搜尋關鍵字插入 Citation，最後自動生成統一格式之參考文獻清單，杜絕人工排版遺漏與格式錯誤。

## 三、圖表排版心理學技巧
1. **圖表置於文中（強烈推薦）**：將圖表置於對應文字說明的同一頁或相鄰下一頁，避免將所有圖表集中塞在附錄或文末。審查委員可在視線 1 頁之內同時核對文字論述與實驗圖表，閱讀體驗最流暢。
2. **前後推導無突兀跳躍**：撰寫時隨時檢查每一個登場的新名詞、新分子，是否都在上一段落有合理的引導與鋪墊。
