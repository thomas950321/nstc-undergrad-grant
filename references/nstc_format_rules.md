# 國科會大專學生研究計畫：制度與格式規範（參考文件）

> 所有數值以國科會官網當年度公告為準。本文件整理自國科會官網、作業要點（113.11.1 修正）與各校研發處公告。

## 一、制度速覽
| 項目 | 內容 |
|---|---|
| 申請資格 | 大學部二年級（含）以上在學學生，不含碩博士生班研究生 |
| 指導教授 | 須有具備指導能力之教授（或副教授、助理教授）承諾指導並填初評意見表 |
| 執行期間 | 當年 7 月 1 日起，為期 8 個月 |
| 研究助學金 | 每月 6,000 元 × 8 個月 = 48,000 元 |
| 耗材/物品/圖書/雜項 | 依計畫實際需要擇優補助，每案上限 20,000 元（實報實銷，結餘繳回） |
| 學術倫理 | 申請學生須完成至少 6 小時學術倫理教育課程（依各校規定上傳證明） |
| 成果報告 | 執行期滿後 1 個月內線上繳交，須經指導教授確認；逾期不列入研究創作獎評獎 |

## 二、線上申請文件（國科會系統）
| 表號 | 文件 | 說明 |
|---|---|---|
| C801 | 綜合資料表 | 系統產生合併檔；務必填寫可即時聯絡之手機號碼 |
| C802 | 研究計畫內容 | **主文以 10 頁為限**（不含參考文獻），PDF 上傳 |
| C801/C802 合併 | 研究計畫摘要表（C803） | 摘要頁（部分學校另列 C803） |
| C804 | 指導教授初評意見表 | 由指導教授上傳，於截止收件日前完成 |
| OTH2 | 歷年成績證明 | 正本掃描上傳 |

申請流程：學生線上填寫並上傳附件 → 繳交送出至就讀系所主管（或學校承辦人）確認 → 指導教授完成初評意見 → 國科會收件。

## 三、格式規範（C802 主文）
| 項目 | 規範 |
|---|---|
| 頁數 | 主文 10 頁為限（參考文獻不計入） |
| 中文字體 | 標楷體 |
| 英文字體 | Times New Roman |
| 字體大小 | 內文 12pt |
| 行距 | 1.5 倍行高 |
| 繳交格式 | PDF（匯出前確認無跑版、無缺字） |
| 圖表 | 研究架構圖／流程圖／甘特圖建議以向量或高解析插入，勿模糊 |

## 四、審查重點（國科會作業要點）
依「國家科學及技術委員會補助大專學生研究計畫作業要點」第十點，審查重點包括：
1. 研究主題之重要性
2. 研究方法及步驟之可行性
3. 學生相關學科成績
4. 指導教授學術研究及指導能力

> 撰寫時每一章節都應能回答「這四點評審會怎麼看我這一頁」。

## 五、常見錯誤（避坑清單）
1. **超過 10 頁**：主文含圖表超過頁數上限，直接失分。
2. **摘要冗長**：評審可能只花 30 秒看摘要，未在第一行點出「為什麼重要」。
3. **動機全憑感覺**：整段「我認為／我覺得」，缺乏數據佐證（內政部、WHO、產業報告等）。
4. **文獻過舊或只有維基**：引用逾 10 年的舊資料、貼維基百科定義；應引用近 3 年期刊論文。
5. **無研究缺口**：只列文獻、沒畫出缺口矩陣，看不出題目必要性。
6. **方法無圖**：只有純文字敘述，沒有架構圖／流程圖／甘特圖，評審無法判斷可行性。
7. **預期成果空泛**：寫「改變人類生活」等級的做不到目標；應量化（1 套原型、1 篇論文投稿）＋質化並陳。
8. **引用不實**：AI 虛構文獻或引用不存在之論文，屬學術倫理問題。
9. **時程誤判**：以國科會截止日為準而漏掉校內更早的截止時間。
10. **未揭露 AI 輔助**：依各校／學門規定如實揭露生成式 AI 使用情況，並本人對內容負責。
