# 國科會大專學生研究計畫 AI 輔助撰寫套件

專為國科會大專學生研究計畫打造的 AI 輔助 Agent Skill 套件。幫你從選題、文獻探討、寫滿 10 頁 C802 計畫書，一路到送件前自審與成果報告撰寫。

---

## 為什麼需要這個套件？

近年國科會審查委員對「生成式 AI 罐頭計畫書」與「AI 虛構文獻」的戒心越來越高：

- **AI 虛構文獻（Hallucination）是學術倫理紅線**：依據國科會與各大專院校學術倫理規範，AI 產出的內容（含數據與引用）必須由申請者親自查核。若計畫書出現不存在的論文或假 DOI，會被視為偽造資料，直接判定未盡查核義務而遭退件。
- **評審對「AI 罐頭感」高度敏感**：充滿「顯著提升」、「深度探索」等空洞詞彙、缺乏真實數據與技術架構圖的文字，在評審眼中只是敷衍了事，無法展現學生獨立思考的能力。
- **格式與頁數硬傷**：C802 計畫書主文規定在 10 頁以內，超過頁數上限或欠缺甘特圖、流程圖，常常直接被扣分。

這個套件不是幫你用 AI 產生空洞的罐頭美文，而是導入專業評審的審稿視角，幫你嚴格執行文獻真實性核對（citation-audit）、找出研究缺口（Research Gap）、精準控制頁數，並附上結構化的甘特圖與架構圖，做出真正能說服評審的計畫書。

## 程式小白 3 分鐘上手

即使你完全沒寫過程式，也能在 1 分鐘內把這個套件載入你的 AI 工具。

### 方式 A：直接在 AI 工具複製專案網址（最簡單）

如果你使用的是 Codex、Cursor 或 Claude Code 等支援 Agent Skills 的工具，直接在對話框輸入：

```text
請幫我載入這個 Skill repo：https://github.com/thomas950321/nstc-undergrad-grant.git
```

載入後，你只需要說：

```text
我想申請今年度的國科會大專生計畫，我的科系是資管系，指導教授建議做「生成式 AI 在客服的應用」，請帶我從 Step 0 開始。
```

AI 就會自動按照規範，一步步帶你完成全套流程。

### 方式 B：手動下載與安裝

把你下載好的 `nstc-undergrad-grant` 資料夾，放到你 AI 工具的技能目錄下：

- **Claude Code**：`~/.claude/skills/nstc-undergrad-grant/`
- **Gemini CLI**：`~/.gemini/skills/nstc-undergrad-grant/`
- **Cursor / 其他工具**：放入專案根目錄的 `.agents/skills/` 或對應技能設定路徑。

## AI 帶你走完 7 大步驟

你不需要死背格式，只要跟著 AI 的對答推進即可：

1. **Step 0 前置檢查**：確認大二以上資格、115 年度最新截止時間、6 小時學術倫理時數、經費試算（助學金 4.8 萬 + 耗材最高 2 萬）。
2. **Step 1 選題與缺口驗證**：對談收斂出 2~3 個候選題目，並自動比對現有方案，確認研究缺口（Research Gap）真正成立。
3. **Step 2 文獻回顧與真實性審計**：整理近 3 年關鍵文獻矩陣。同步啟動引用審計，嚴防 AI 虛構論文。
4. **Step 3 C802 計畫書撰寫（精準 10 頁上限）**：
   - 摘要 C803（0.5 頁）：300 字黃金公式（背景 1 句 → 痛點 1 句 → 解法 2 句 → 貢獻 1 句）。
   - 動機與目的（1~1.5 頁）：佐證數據與痛點情境圖。
   - 文獻探討（2.5~3 頁）：理論架構與競品限制比較表。
   - 研究方法與步驟（3~4 頁）：包含系統/工程架構圖，以及 8 個月 Mermaid 甘特圖。
   - 預期成果（1 頁）：量化產出與質化效益。
5. **Step 4 評審視角 7 維度自審**：模擬評審從原創性、論證、文獻、方法、清晰度、影響力、技術正確性等 7 個維度評分，確保總分達標（≥28/35 分）。
6. **Step 5 送件前 Check**：檢查 12pt 標楷體/Times New Roman、1.5 倍行高、PDF 無跑版、C801~C804 表單與 AI 使用揭露。
7. **Step 6 成果報告指引**：計畫通過並執行期滿後，協助撰寫成果報告，維護評獎資格。

## 專案目錄結構

```
nstc-undergrad-grant/
├── SKILL.md                        # 主技能檔案：完整工作流程（Step 0~6）
├── references/
│   ├── nstc_format_rules.md        # 國科會制度、表號、格式規範與 10 大避坑清單
│   ├── section_template.md         # 摘要黃金公式與各章節詳細寫法模板
│   └── reviewer_checklist.md       # 7 維度評審自審清單與國科會審查重點對照
└── prompts/
    ├── abstract.md                 # 300 字摘要生成與 30 秒評審壓力測試 Prompt
    ├── gap_analysis.md             # 研究缺口矩陣與文獻真偽驗證 Prompt
    └── gantt.md                    # 8 個月時程 Mermaid 甘特圖 Prompt
```

## 重要提醒與聲明

- 所有申請時程、法規與經費金額，請務必以國科會官網（nstc.gov.tw）當年度最新公告為準。
- 生成式 AI 僅為研究與寫作的輔助工具。請勿偽造數據或抄襲，並請依各校及各學門規定如實揭露 AI 使用情形。
- 本套件為社群開源輔助範本，非國科會官方發行文件。正式送件請以國科會線上申請系統之格式為準。
