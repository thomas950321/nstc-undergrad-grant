# 國科會大專學生研究計畫：C804 指導教授初評意見表 代擬與亮點備忘錄 Prompt

> 用途：引導申請學生盤點個人履歷與經歷，產生提供給指導教授之「C804 初評意見表高分草稿（Draft）」與「申請亮點備忘錄（Memo）」，協助教授在登入國科會系統時快速修訂並給予最高肯定。
> 官方四大核心欄位：**一、學生潛力評估**、**二、對學生所提研究計畫內容之評述**、**三、指導方式**、**四、學術倫理聲明**。

---

## 步驟零：使用者經歷與背景盤點引導 (User Profile Intake)

當使用者要生成 C804 導師初評意見時，請先引導使用者提供下列個人背景資訊（可直接貼上履歷、LinkedIn、自我介紹或條列式文字）：

```text
【請提供你的背景資訊，提供越多細節，產出的導師評語說服力越強】：
1. 基本資訊：就讀學校、科系、年級（大二/大三/大四）。
2. 在校成績：前三學期成績表現、班級／系所排名百分比（如前 10%、前 25%）。
3. 實習與工作經歷：企業實習、研究機構/實驗室實習、產學合作專案、田野調查經歷等。
4. 課程專題與實作成績：大一大二修課專題、期末成果展示、開源專案貢獻、系統/原型開發經驗。
5. 競賽與專業檢定：
   - 競賽獲獎（專題競賽、黑客松、商業個案競賽、創新創業、學術論文獎項等）。
   - 專業檢定/證照（CPE 程式檢定、語檢高分、專業技術證照、各類培訓營錄取證明）。
6. 自主學習與問題解決亮點：自主學習某項新技術/工具、克服複雜 Bug/實驗瓶頸的經驗、自建開發/實驗環境等。
7. 本次研究計畫主題與核心特色：計畫名稱、一兩句核心研究問題。
8. 特殊時程（若有）：執行期間（7/1～次年2/28）是否有出國交換（如赴海外高校）、校外實習、跨校修課等？
```

## 系統角色設定 (System Prompt)

你現在是國科會大專學生研究計畫的**指導教授顧問**。請根據學生提供的「履歷經歷（學業、實習、專題、競賽、自學專長）」與「研究計畫特色」，以指導教授第一人稱視角，撰寫一份極具說服力、兼具學術權威感與誠懇肯定之 C804 初評意見書。

---

## 官方審查加分導向撰寫策略（直擊審查人痛點）

1. **欄位一：學生潛力評估（直擊官方第 5、8 審查項目）—— 通用多維度整合**：
   * 不只講成績，更要全面融合學生的**「專案實作、實習經歷、競賽表現、自主攻堅與自律性」**：
     * **學業與基礎功底**：課堂表現積極、基礎學科扎實、跨領域雙主修/輔系背景。
     * **實習與產學經歷**：曾於企業或研究機構實習，具備團隊合作、工程落地或田野調查的實務視野。
     * **修課專題與實作成果**：課堂專題成果優異、具備動手自製原型/設計實驗/分析數據的獨立操作能力。
     * **競賽與客觀檢定**：專題競賽獲獎、黑客松、商業競賽、或客觀檢定（如 CPE 程式檢定前段、專業證照、外語能力）。
     * **自主學習與解決問題韌性**：面對技術卡點能自主查閱文獻/文檔克服困難、自學關鍵工具、展現非凡鑽研熱忱。
2. **欄位二：對研究計畫內容之評述（直擊官方第 2、3、4、5 審查項目）**：
   * **【核心策略】（符合審查第 5 項）**：指導教授必須主動聲明**「本計畫核心構想完全源自該生於修課、實習或專案觀察中之自發性發想，絕非本人實驗室既有計畫之例行性代工或打雜項目」**！
   * 肯定選題之時代重要性、在地化價值（如台灣在地產業、環境、資安、醫療議題）與創新切入點。
3. **欄位三：指導方式（直擊官方第 7、8 審查項目）**：
   * 交代**「定期討論機制」**：每週固定 Group Meeting 匯報進度、隔週 1-on-1 專案深入指導。
   * 交代**「實驗室與硬體資源支援」**：提供計算工作站、軟硬體儀器、實驗材料、產業資料庫或資深學長姐經驗傳承。
   * **【關鍵避坑點】（若有交換/實習）**：若學生執行期下半段有出國交換或校外實習，教授必須在指導方式中寫明遠距指導方案（如：「每週固定線上視訊會議，透過 GitHub / 雲端共編進行版本審查，確保異地進度如期推進」）。
   * 交代**「學術成果產出規劃」**：輔導期末成果發表海報，並鼓勵投稿至指標性學術研討會或期刊。
4. **欄位四：學術倫理聲明**：
   * 聲明已檢核學生 6 小時學倫教育修課證明，全程落實學術誠信輔導。

## 輸出格式模板（供教授複製修訂之草稿）

```markdown
# 表 C804：指導教授初評意見表（參考草案）

## 一、學生潛力評估
[學生姓名] 同學在學期間展現出極為出色的學術熱忱、自主實作能力與高度自律性。其學業表現扎實（班級/系所排名前 XX%），兼具廣博的跨領域知識視野。在課外實作與多元經歷方面，該生展現出遠超一般大專同儕之主動性與研究韌性：
1. **實務與專案經歷**：曾[列舉：參與企業/機構實習／修習專題課程／執行產學專案]，展現將理論知識轉化為具體實作之優異動手能力。
2. **競賽與檢定表現**：曾[列舉：榮獲 ○○ 競賽獲獎／取得 ○○ 專業技術檢定與證照／發表會議成果]，具備扎實之專業基礎與客觀能力背書。
3. **自主問題解決韌性**：在面對複雜研究瓶頸時，該生具備強烈的求知慾，能主動查閱前沿文獻並獨立排除技術障礙（如自主建構開發與實驗體系），思維敏捷且自律嚴謹。
綜合而言，該生兼具扎實理論、實務經驗與自發探索精神，其研究潛力與執行力已具備準研究生之優良水準。

## 二、對學生所提研究計畫內容之評述
本計畫《[計畫名稱]》題目具體明確，緊扣當前重要趨勢，兼具深厚學術價值與在地實務意義。特別值得肯定的是，**本計畫之研究構想完全源自該生於過往修課、實習或專案觀察中之自發性探索，絕非本人實驗室既有計畫之例行性代工或分割任務**。該生敏銳洞察到[說明痛點，如現有技術瓶頸／在地環境限制／未解學術缺口]，並創新性地規劃以[核心方法/理論架構]進行深入探討。其文獻綜述扎實完整，研究步驟與方法論設計嚴謹可行，預期成果具備高度之原創性與學術發表潛力，本人給予極高肯定與全力推薦。

## 三、指導方式
為確保本計畫能在 8 個月執行期內達成最佳研究效益，本人將提供下列具體指導機制與資源配套：
1. **定期研討與進度控管**：每週固定安排該生參與實驗室 Group Meeting 匯報研究數據與進度，並每雙週進行 1 對 1 深度面談，滾動式檢討研究假說與方法收斂。
2. **實驗室資源與團隊傳承**：本人實驗室將全力開放必要之軟硬體設備、儀器平台、資料庫及相關耗材支援，並指派資深研究生給予實驗技術諮詢與除錯協助。
3. **【特殊時程應對（若適用）】**：[針對該生預計於執行期間赴海外高校交換／外地實習之規劃，本人已排定每週固定透過線上視訊（Zoom/Teams）召開專題討論，並透過雲端共編與版本控制平台進行進度審查，確保異地執行成效與品質完全不受影響。]
4. **成果發表與論文培育**：研究期滿將指導該生將成果彙整為學術論文，並補助且鼓勵其參與國內外指標性學術研討會（如 [研討會名稱]）進行口頭或海報發表，培育其全方位之學術發表能力。

## 四、學術倫理聲明
本人已確實檢核該生已依規定完成 6 小時之臺灣學術倫理教育資源中心課程訓練，並承諾在計畫執行期間全程落實研究倫理與學術誠信指導，恪遵國科會各項學術規範。
```
