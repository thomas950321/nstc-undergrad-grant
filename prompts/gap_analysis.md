# 研究缺口分析 Prompt

## Prompt 1：競品／現有方案矩陣
```
請針對「[題目]」領域，先檢索近 3 年的相關研究與產品，
列出目前市面上／學術界常見的 3~5 種解決方案，
並以表格比較其「優點、缺點、技術限制」，欄位如下：

| 方案/文獻（作者, 年） | 核心方法 | 優點 | 缺點/限制 | 適用情境 |

最後以一句話指出本研究可以切入的「研究缺口（Research Gap）」，
並說明：為何現有方案無法解決[目標痛點]，本研究的差異化切入點為何。
請對照至少 3 篇真實存在且可查證的文獻，附上出處。
```

## Prompt 2：缺口成立性驗證（選題卡複檢）
```
我考慮採用以下題目進行研究，請以嚴謹角度驗證缺口是否成立：

題目：[題目]
一句話研究問題：[研究問題]
初步方法：[方法]

請回答：
1. 這個問題是否已被大規模研究回答過？（列出可能的重疊文獻）
2. 若已存在類似研究，本研究的差異性（對象/場域/方法/資料）是什麼？
3. 最小可行實驗是什麼？需要哪些資源（設備、資料、受測者）？
4. 可行性風險（時間、成本、資料可得性）與緩解方式。
5. 結論：缺口成立（推薦執行）／部分成立（需調整）／不成立（建議更換題目）
```

## Prompt 3：文獻表建置
```
請協助建立我計畫書「文獻探討」章節的文獻矩陣。
主題：[主題]
已收集文獻清單：[貼上 DOI 或標題清單]

請為每篇輸出：研究目的／方法／樣本資料／主要結果（含數值）／限制／
與本研究之關聯（直接相關、間接相關、可作為理論依據）。
最後依「近 3 年優先、核心理論優先」排序，並標示哪些是必須引用、哪些可選。
若清單中有無法查證的條目，請明確標示「未驗證」，不要假設其存在。
```

## 使用守則
- 所有文獻條目必須可查證；AI 無權虛構 DOI 或論文。
- 產出的缺口論述應轉化為 C802「研究動機」與「文獻探討」兩章的核心論點。
