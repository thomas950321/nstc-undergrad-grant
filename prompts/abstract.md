# 摘要生成／潤飾 Prompt

## Prompt 1：從草稿生成結構化摘要（300 字內）
```
我是一名大專學生，正在撰寫國科會大專學生研究計畫（C803 摘要/摘要頁）。
請將以下草稿改寫為「學術、客觀、精簡」的中文摘要，300 字以內，
嚴格依序包含四段：背景（1 句）、痛點（1 句，含數據或文獻佐證）、
研究方法（2 句）、預期貢獻（1 句，須量化）。

研究題目：[題目]
主要想解決的痛點：[痛點]
初步構想：[草稿內容]

輸出後請另附一行「字數統計」，並檢查有無空泛形容詞（如「顯著改善」而無指標）。
```

## Prompt 2：摘要強度檢查（30 秒測試）
```
請以「只花 30 秒讀摘要的國科會評審」身分審查下面這段摘要：
1. 第一句話是否點出「為什麼重要」？若否，請重寫第一句。
2. 是否有具體數據、方法名或可驗證的預期成果？指出缺乏處。
3. 逐句標記可刪除的空泛語句。
4. 輸出修改版（300 字內）與修改說明。

摘要草稿：[貼上摘要]
```

## Prompt 3：中英對照版（若需雙語輸出）
```
請將下列中文摘要翻譯為英文摘要（200 字內），
保持學術語氣與專有名詞一致，並列中文 300 字版與英文版。
摘要完成後以表格輸出，欄位：中文版／英文版／字數。

中文摘要：[貼上摘要]
```

## 使用守則
- 摘要最終版本仍須由使用者逐字確認，勿整段直接複製貼上。
- 涉及數據、文獻時，AI 產出的數字與引用必須由使用者以真實來源核對。
